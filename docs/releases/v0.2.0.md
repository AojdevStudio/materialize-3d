## Code capabilities

- Conversational sign and general-part design through the in-app assistant. OpenAI and Anthropic remain available with your own API key.
- General parts generated as build123d code in an isolated CAD worker, followed by independent inspection and mesh measurements.
- A part detail in the Signs view with a rendered view, revision history, measured requirements, complete checks, and print warnings. This GUI was added in PR 34.
- Human approval bound to the exact package SHA-256 and the recorded warnings. The assistant and external agents cannot approve.
- P2S 0.4 mm Bambu project 3MF export through the app's Save dialog. A part package includes its STEP model. Bambu Studio 02.08.02.61 remains a separate installation.
- A bundled CAD helper and pinned runtime for the macOS release. End users do not need a source checkout, developer tools, or a CAD cache.

## Requirements and limits

- Apple Silicon and macOS 26.0 or later. Intel Mac, Windows, and Linux release builds are not offered.
- Bambu Studio 02.08.02.61. Other slicer versions are refused for this workflow.
- An OpenAI or Anthropic API key for chat. The provider bills usage at its own rates.
- A Bambu Lab P2S with a 0.4 mm nozzle for the exported project. Three-color signs need an AMS and three filaments.
- Materialize 3D does not send the exported package to a printer. Open it in Bambu Studio, review it, and print from there.
- Automated checks do not establish physical fit, strength, or a successful print.

## Required publication evidence

Before publication, the release owner must complete the [release procedure](../releasing.md) and attach its software acceptance record to the release. The release body and attached record must identify the exact tagged source commit and final DMG checksum. Keep these measured values outside tracked source to avoid changing the commit that produced the DMG. Signed and notarized rehearsals, wrapper checks, and separate-machine headless installation support the workflow. They do not establish GUI acceptance of the final DMG.

The record must include these results for the final DMG. Required software checks must pass before publication. Report every failure or unrun check with its reason.

- Signed and notarized DMG from a clean tagged build without `ALLOW_UNTAGGED`. App and helper signatures, signing team, Gatekeeper assessments, macOS minimum, exact bundle inventory, pinned runtime verification, and absence of the e2e endpoint and scripted dialogs.
- Clean-account installation and CAD self-test using only the installed app's helper and runtime, without developer environments or caches. Label each machine and test identity separately from GUI and wrapper runs.
- Installed GUI OpenAI chat builds for both the sign and a corrected general part in the [Mac acceptance recipe](../verify-on-mac.md). Record the model, prompts, tool results, measured requirements, checks, and warnings. Both GUI isolation options require fresh app data, a test keychain, and the system-only `PATH`.
- Direct human GUI approval and native Save dialog export for both objects. Record revision IDs and matching full build, approval, and export hashes, plus successful P2S 0.4 mm import and slicing in Bambu Studio 02.08.02.61.
- Installed-app relaunch, provider and keychain persistence, cancellation, interruption, identical-spec reuse, migration, and MCP security checks. Include the invalid OpenAI credential, unavailable Bambu Studio, and CAD execution failures, their recovery actions, and successful builds after recovery. Label each check separately.
- Physical acceptance remains pending until Ossie records an actual print and inspection. Only Ossie decides to print. State this limit separately from software acceptance.

The earlier desk clip candidate labeled R3 is excluded from release acceptance. Its 1.82 mm rounded tip does not meet the requested 3 mm minimum wall. Passing selected local measurements does not accept that candidate.

## Installation

Download `Materialize-3D-0.2.0-macos-arm64.dmg`, its `.sha256` file, and the software acceptance record from the [published release](https://github.com/AojdevStudio/materialize-3d/releases/tag/v0.2.0). Follow the [Mac install guide](../install-macos.md). Compare the downloaded DMG's full checksum with both the checksum file and the record. Stop on a mismatch or missing evidence.

```bash
shasum -a 256 ~/Downloads/Materialize-3D-0.2.0-macos-arm64.dmg
```
