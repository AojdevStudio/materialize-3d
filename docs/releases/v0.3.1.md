# Materialize 3D 0.3.1

Source release notes. Version 0.3.1 makes the 0.3.0 chat studio match its design. It adds a first-launch setup, a Settings screen, and slicing for the printer you pick. It also changes the chat, the sidebar, the start screen, and the print files bar. The [Releases page](https://github.com/AojdevStudio/materialize-3d/releases) reports distribution status.

## Before you update

- On 0.3.0, the app offers 0.3.1 at launch. **Update now** installs it. **Later** keeps 0.3.0 and asks again at the next launch.
- On 0.2.2, the app offers 0.3.1 too. That update replaces the old app with the chat studio. Read the [0.3.0 notes](v0.3.0.md#before-you-update) first.
- On 0.2.1 or older, install 0.3.1 by hand from its DMG.
- 0.3.1 opens the projects and chats that 0.3.0 made ([#276](https://github.com/AojdevStudio/materialize-3d/pull/276)). Your sign-ins stay in the macOS Keychain, and 0.3.1 reads them from there ([#286](https://github.com/AojdevStudio/materialize-3d/pull/286)).
- **You do not see setup.** If 0.3.0 ran on this Mac, 0.3.1 counts the Mac as set up and opens the studio ([#276](https://github.com/AojdevStudio/materialize-3d/pull/276)). The same choices are in Settings. The gear at the bottom of the sidebar opens it. **Fix in setup** on a row that is not Ready opens Check your Mac. **Change** opens Your printer.
- **The sign-in form left the chat.** 0.3.0 showed an API key and proxy form above the prompt. In 0.3.1 a banner names what is missing, and **Fix in setup** opens Check your Mac ([#280](https://github.com/AojdevStudio/materialize-3d/pull/280)). The Claude row there has **Sign in** and **Use a key**. The ChatGPT row has **Sign in**.
- **OpenCode Go has no sign-in screen.** The old form was the only place to enter an OpenCode Go key. A key you saved in 0.3.0 stays in the Keychain, and the app still reads it. You cannot add or replace an OpenCode Go key in 0.3.1.
- **The model picker is shorter.** Older models left its list ([#269](https://github.com/AojdevStudio/materialize-3d/pull/269)). A project that uses an older model keeps it and still runs on it.
- **Your printer stays the P2S with PETG** until you change it in Settings ([#281](https://github.com/AojdevStudio/materialize-3d/pull/281)).
- **Astra stays on.** Settings saved in 0.3.0 keep the agent's GPT 6 Astra tool ([#279](https://github.com/AojdevStudio/materialize-3d/pull/279)). Without a ChatGPT sign-in, a turn can still stop and ask for one. [Known issues](#known-issues) has more.
- **The chat shows no file card** after a turn that wrote files. The print files bar and the Files tab keep the same actions ([#272](https://github.com/AojdevStudio/materialize-3d/pull/272)).
- **The start screen offers your 2 newest projects**, not 3 ([#270](https://github.com/AojdevStudio/materialize-3d/pull/270)).

## First-launch setup

A new install opens setup before the studio. Setup has five screens.

- **Welcome.** It says what the app does and what leaves your Mac. **Start setup** goes on ([#276](https://github.com/AojdevStudio/materialize-3d/pull/276)).
- **Check your Mac.** A row each for Claude, ChatGPT, Bambu Studio, uv, and Python. Each row says Ready or names what is missing. A sign-in row has **Sign in**. A missing uv or Python has **Copy install command**. **Check again** runs the check again. **Continue** waits for one sign-in, uv, and Python. Without Bambu Studio it reads **Continue without a slicer** ([#276](https://github.com/AojdevStudio/materialize-3d/pull/276)).
- **Pick a model.** The models of the agents you signed in to, with one line on what each suits. Your pick is the model new projects start with. A switch lets the main agent ask GPT 6 Astra for drawings. The switch needs a ChatGPT sign-in ([#279](https://github.com/AojdevStudio/materialize-3d/pull/279)).
- **Your printer.** The printer, nozzle, filament, plate, and quality that Bambu Studio last used, with **Looks right** and **Change**. When the app cannot read them, you pick each one from a list. Without the validated Bambu Studio, setup passes this screen ([#283](https://github.com/AojdevStudio/materialize-3d/pull/283)).
- **Ready.** A summary of the agent, the slicer, the printer, and the build tools. **Start a project** opens the studio ([#279](https://github.com/AojdevStudio/materialize-3d/pull/279), [#283](https://github.com/AojdevStudio/materialize-3d/pull/283)).

## Settings

A gear at the bottom of the sidebar opens Settings ([#284](https://github.com/AojdevStudio/materialize-3d/pull/284)). It has four sections.

- **Agents and models.** Each sign-in's state, the default model for new projects, and the Astra switch.
- **Slicer and printer.** Bambu Studio's state and the chosen printer. **Change** opens setup's Your printer screen.
- **Build tools.** uv and Python.
- **Projects folder.** Where your projects live, with **Reveal**.

A row that is not Ready has **Fix in setup**. Keys and proxies are not in Settings. They stay in Check your Mac.

## Slicing for your printer

0.3.0 always sliced for a P2S with a 0.4 mm nozzle and PETG. 0.3.1 slices for the printer, nozzle, filament, plate, and quality you chose ([#281](https://github.com/AojdevStudio/materialize-3d/pull/281), [#283](https://github.com/AojdevStudio/materialize-3d/pull/283)).

- The app reads the last used settings from Bambu Studio. It does not change them.
- You can choose any Bambu Lab printer that Bambu Studio 02.08.02.61 has presets for.
- A filament preset you made yourself is read as the Bambu Lab preset it came from. Only a Bambu Lab preset can be saved.
- The agent learns the printer when it slices. Its answer names the printer and the plate.

## Setup needed again

When a sign-in or the slicer is gone, a banner at the top of the chat says so ([#280](https://github.com/AojdevStudio/materialize-3d/pull/280)).

- **A sign-in is gone.** The banner reads "Claude is logged out. Your chats are saved. Log in to keep working." The prompt reads "Log in to an agent to send", and Send is off. **Fix in setup** opens Check your Mac.
- **It shows when the chat opens.** A sign-in deleted from the Keychain outside the app counts as gone at once, not after a failed send ([#286](https://github.com/AojdevStudio/materialize-3d/pull/286)).
- **The slicer is gone.** The banner reads "No slicer found. You can still design parts, but you won't get print-ready 3MF files." Send stays on.
- **uv or Python is gone.** The banner names it, and Send is off.

## Chat, sidebar, and files

- **Model picker.** A short list by short name: Opus 5.5, Sonnet 5.5, and GPT 6.1 Sol, for the agents you signed in to. The button shows the short name ([#269](https://github.com/AojdevStudio/materialize-3d/pull/269)). Fable 5.2 is not on the list yet. It needs a newer agent engine.
- **Chat.** The title bar and the raw model ID line are gone. Each reply has its model's mark and short name above it ([#271](https://github.com/AojdevStudio/materialize-3d/pull/271)). A short chat sits at the bottom, above the prompt ([#277](https://github.com/AojdevStudio/materialize-3d/pull/277)). **Stop** is a black button with a square icon ([#272](https://github.com/AojdevStudio/materialize-3d/pull/272)).
- **Step times.** Each finished step in the run trace shows how long it took, such as `<1s`, `3s`, or `1:05` ([#278](https://github.com/AojdevStudio/materialize-3d/pull/278)).
- **Start screen.** Each recent project's chip has a status line: working, 3MF ready, guide ready, printed, or draft ([#270](https://github.com/AojdevStudio/materialize-3d/pull/270)).
- **Sidebar.** A Projects row with the project count, a search button that filters projects by title, and the chosen printer's name in the footer ([#282](https://github.com/AojdevStudio/materialize-3d/pull/282)).
- **Print files bar.** A second line read from the 3MF. One file shows its name, print time, and filament weight. Several files show the printer, filament, and layer height they share. **Open in Bambu Studio** has the Bambu Studio mark, and the Files tab shows its count ([#273](https://github.com/AojdevStudio/materialize-3d/pull/273)).

## Requirements and limits

These are the same as in 0.3.0, with one change.

- Apple Silicon and macOS 26.0 or later.
- A sign-in to Claude or ChatGPT. Your provider's plan or API charges apply. The app is free.
- [uv](https://docs.astral.sh/uv/) and a Python it can run. After you install uv, run `uv python install`.
- [Bambu Studio 02.08.02.61](https://github.com/bambulab/BambuStudio/releases/tag/v02.08.02.61), installed separately. The app refuses other versions for slicing.
- **Changed:** to print, a Bambu Lab printer that Bambu Studio 02.08.02.61 has presets for. 0.3.0 needed a P2S with a 0.4 mm nozzle.
- The app does not send jobs to a printer. Open the 3MF in Bambu Studio, check it, and print from there.
- Automated checks do not prove physical fit, strength, or a good print.

## Known issues

- Drawings and other agent pages that set their own look stay light in dark mode ([#233](https://github.com/AojdevStudio/materialize-3d/issues/233)).
- At a launch in dark mode, the native window shows light for about 0.2 seconds before the page paints black ([#236](https://github.com/AojdevStudio/materialize-3d/issues/236)).
- If the agent writes a guide step with no body, the guide page breaks and shows no step panel or buttons ([#246](https://github.com/AojdevStudio/materialize-3d/issues/246)).
- While **Update now** waits for the agent, the banner says "Waiting for 1 build to finish." It means the agent's work ([#228](https://github.com/AojdevStudio/materialize-3d/issues/228)).
- The update does not back up your chats before it installs ([#227](https://github.com/AojdevStudio/materialize-3d/issues/227)).
- If macOS holds the Python check for a permission prompt, the app says Python is missing. Answer the prompt, then press **Check again** ([#208](https://github.com/AojdevStudio/materialize-3d/issues/208)).
- If the engine starts slowly, the start screen's model picker can show the model from before your last pick. The app keeps your pick ([#274](https://github.com/AojdevStudio/materialize-3d/issues/274)).
- On a Mac that ran 0.3.0 with no ChatGPT sign-in, Settings shows the Astra switch off and locked. The agent still has the Astra tool, so a turn can stop and ask for a ChatGPT sign-in ([#288](https://github.com/AojdevStudio/materialize-3d/issues/288)).
- A quit while the agent slices may leave that step marked as failed after you open the app again. Ask the agent to slice again ([#266](https://github.com/AojdevStudio/materialize-3d/issues/266)).

## Publication requirements

Follow the [release procedure](../releasing.md). Publishing 0.3.1 as **Latest** offers it to every installed 0.3.0 and 0.2.2 app at its next launch. Publish only after the required checks pass.

- Build a signed and notarized DMG and the update assets from a clean checkout of the `v0.3.1` tag, without `ALLOW_UNTAGGED`.
- Run the [installed GUI checklist](../verify-on-mac.md) on that exact DMG.
- Attach the software acceptance record to the release. The record and the release body name the exact tagged source commit and the full DMG checksum. Keep those values out of tracked source.
- Download the published files and compare them with the build, as the release procedure's last step says.

## Installation

Download `Materialize-3D-0.3.1-macos-arm64.dmg` and its `.sha256` file from the [published release](https://github.com/AojdevStudio/materialize-3d/releases/tag/v0.3.1). Follow the [Mac install guide](../install-macos.md). Compare the downloaded DMG's full checksum with the checksum file, and stop on a mismatch.

```bash
shasum -a 256 ~/Downloads/Materialize-3D-0.3.1-macos-arm64.dmg
```

On 0.3.0, **Update now** installs 0.3.1 for you.
