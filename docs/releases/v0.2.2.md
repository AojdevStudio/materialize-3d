# Materialize 3D 0.2.2

Source release notes. Version 0.2.2 adds the in-app updater and fixes bugs found after 0.2.1. It is the first release that installed apps can update from. The [Releases page](https://github.com/AojdevStudio/materialize-3d/releases) reports distribution status.

## Who should update

- Everyone on the 0.2.1 or 0.2.0 Mac app. Install 0.2.2 by hand from its DMG once. After that, later releases arrive through the app.
- Anyone who downloads models from MakerWorld. Downloads now reach Model Library at once, with the right model, files, and numbers.

## The app updates itself

At launch, the app checks the latest GitHub release ([#78](https://github.com/AojdevStudio/materialize-3d/pull/78)). When a newer version exists, a banner offers **Update now** or **Later**.

- **Update now** downloads the update and checks its signature. It backs up the database and print queue, installs, and restarts. If the backup fails, the update stops and the app keeps running.
- **Update now** waits for a running CAD build ([#86](https://github.com/AojdevStudio/materialize-3d/pull/86)) and a running STL slice ([#101](https://github.com/AojdevStudio/materialize-3d/pull/101)) before it restarts.
- **Later** asks again at the next launch.
- **Settings > About** shows the installed version and checks for updates on request.

The app reads only releases published as Latest. Drafts and prereleases never reach it.

## Other changes

- **AI server address.** Each AI provider can use a saved server address, such as a gateway, instead of the provider's own server. While an address is saved, you can also enter any model ID ([#90](https://github.com/AojdevStudio/materialize-3d/pull/90)).
- **Database guard.** The app refuses a database with a newer schema than it supports, changes nothing in it, and says how to recover ([#87](https://github.com/AojdevStudio/materialize-3d/pull/87)). Versions 0.2.1 and 0.2.2 use the same schema, so a move between them is not refused.

## Fixes

- **MakerWorld downloads.** A download shows in Model Library at once ([#76](https://github.com/AojdevStudio/materialize-3d/pull/76)). Each model lists only its own files ([#84](https://github.com/AojdevStudio/materialize-3d/pull/84)). A download that finishes after you leave the model page keeps its model, and a second download of a model keeps every file ([#98](https://github.com/AojdevStudio/materialize-3d/pull/98)). On macOS, two overlapping downloads of the same file URL still cannot be matched when they finish, so neither reaches the Library ([#116](https://github.com/AojdevStudio/materialize-3d/issues/116)).
- **MakerWorld numbers.** The panel shows the real rating, review count, downloads, and print files ([#77](https://github.com/AojdevStudio/materialize-3d/pull/77)).
- **API keys.** A typed but unsaved API key no longer follows a provider switch in Settings ([#96](https://github.com/AojdevStudio/materialize-3d/pull/96)) or in onboarding ([#114](https://github.com/AojdevStudio/materialize-3d/pull/114)). Chat hides an API key that an error reply quotes in encoded form, and a failed chat turn writes a safe line to the app log ([#100](https://github.com/AojdevStudio/materialize-3d/pull/100)).
- **Contrast.** Disabled button text meets WCAG AA contrast ([#109](https://github.com/AojdevStudio/materialize-3d/pull/109)).
- **Linux source builds.** One failed download no longer fails every later download in the session. The app moves to Tauri 2.12 for this fix ([#105](https://github.com/AojdevStudio/materialize-3d/pull/105)). Overlapping downloads of one file URL each land in their own file ([#115](https://github.com/AojdevStudio/materialize-3d/pull/115)).

## Requirements and limits

Requirements are the same as 0.2.0. The [0.2.0 release notes](v0.2.0.md#requirements-and-limits) list them. The database schema does not change, so an update keeps your signs, parts, approvals, and history. The CAD runtime does not change either.

## Installation

Download `Materialize-3D-0.2.2-macos-arm64.dmg` and its `.sha256` file from the [published release](https://github.com/AojdevStudio/materialize-3d/releases/tag/v0.2.2). Follow the [Mac install guide](../install-macos.md). Compare the downloaded DMG's full checksum with the checksum file, and stop on a mismatch.

```bash
shasum -a 256 ~/Downloads/Materialize-3D-0.2.2-macos-arm64.dmg
```

To update from 0.2.1, quit the app and replace it in **Applications** with the 0.2.2 app. Your data and Keychain items stay.
