# Materialize 3D 0.3.2

Source release notes. Version 0.3.2 makes the Settings sidebar look like the main sidebar. Nothing else in the app changes. The [Releases page](https://github.com/AojdevStudio/materialize-3d/releases) reports distribution status.

## Before you update

- On 0.3.1, the app offers 0.3.2 at launch. **Update now** installs it. **Later** keeps 0.3.1 and asks again at the next launch. You have nothing to set up.
- On 0.3.0, the app offers 0.3.2 too. It brings the changes of 0.3.1 with it. Read the [0.3.1 notes](https://github.com/AojdevStudio/materialize-3d/blob/v0.3.2/docs/releases/v0.3.1.md#before-you-update) first.
- On 0.2.2, the app offers 0.3.2 too. That update replaces the old app with the chat studio. Read the [0.3.0 notes](https://github.com/AojdevStudio/materialize-3d/blob/v0.3.2/docs/releases/v0.3.0.md#before-you-update) first.
- On 0.2.1 or older, install 0.3.2 by hand from its DMG.

## Settings sidebar

The list on the left of Settings now looks like the main sidebar ([#296](https://github.com/AojdevStudio/materialize-3d/pull/296)).

- It has the same width and the same text size.
- An item you point at or select gets the same fill as a project in the main sidebar, in light and dark mode.

The four sections and what they hold do not change.

## Requirements and limits

These are the same as in 0.3.1.

- Apple Silicon and macOS 26.0 or later.
- A sign-in to Claude or ChatGPT. Claude takes a subscription sign-in or a key. ChatGPT takes its own sign-in. Your provider's plan or API charges apply. The app is free.
- [uv](https://docs.astral.sh/uv/) and a Python it can run. After you install uv, run `uv python install`.
- [Bambu Studio 02.08.02.61](https://github.com/bambulab/BambuStudio/releases/tag/v02.08.02.61), installed separately. The app refuses other versions for slicing.
- To print, a Bambu Lab printer that Bambu Studio 02.08.02.61 has presets for.
- The app does not send jobs to a printer. Open the 3MF in Bambu Studio, check it, and print from there.
- Automated checks do not prove physical fit, strength, or a good print.

## Known issues

- Drawings and other agent pages that set their own look stay light in dark mode ([#233](https://github.com/AojdevStudio/materialize-3d/issues/233)).
- At a launch in dark mode, the native window shows light for about 0.2 seconds before the page paints black ([#236](https://github.com/AojdevStudio/materialize-3d/issues/236)).
- If the agent writes a guide step with no body, the guide page breaks and shows no step panel or buttons ([#246](https://github.com/AojdevStudio/materialize-3d/issues/246)).
- While **Update now** waits for the agent, the banner says "Waiting for 1 build to finish." It means the agent's work ([#228](https://github.com/AojdevStudio/materialize-3d/issues/228)).
- The update does not back up your chats before it installs ([#227](https://github.com/AojdevStudio/materialize-3d/issues/227)).
- If macOS holds the Python check for a permission prompt, the app says Python is missing. Answer the prompt, then press **Check again** ([#208](https://github.com/AojdevStudio/materialize-3d/issues/208)).
- If the engine starts slowly, the start screen's model picker can show the model from before your last pick. The app keeps your pick ([#274](https://github.com/AojdevStudio/materialize-3d/issues/274)).
- On a Mac that ran 0.3.0 with no ChatGPT sign-in, Settings shows the Astra switch off and locked. The agent still has the Astra tool, so a turn can stop and ask for a ChatGPT sign-in ([#288](https://github.com/AojdevStudio/materialize-3d/issues/288)).
- If uv or Python stops answering, Check your Mac can stay on Checking and Send stays off. Quit the app, end the stuck uv or Python, and open the app again ([#275](https://github.com/AojdevStudio/materialize-3d/issues/275)).
- A quit while the agent slices may leave that step marked as failed after you open the app again. Ask the agent to slice again ([#266](https://github.com/AojdevStudio/materialize-3d/issues/266)).
- If the first send of a new project fails and you edit the message before you retry, the retry can make a second project. The first one keeps an empty chat ([#209](https://github.com/AojdevStudio/materialize-3d/issues/209)).
- If you send while a chat is still loading and its agent is working, the app says the agent is still working. Wait, then send again ([#209](https://github.com/AojdevStudio/materialize-3d/issues/209)).
- Some light text is hard to read: the prompt's placeholder, the key form's placeholders, and the disabled Send and Save buttons ([#196](https://github.com/AojdevStudio/materialize-3d/issues/196), [#211](https://github.com/AojdevStudio/materialize-3d/issues/211)).

## Publication requirements

Follow the [release procedure](https://github.com/AojdevStudio/materialize-3d/blob/v0.3.2/docs/releasing.md). Publishing 0.3.2 as **Latest** offers it to every installed 0.3.1, 0.3.0, and 0.2.2 app at its next launch. Publish only after the required checks pass.

- Build a signed and notarized DMG and the update assets from a clean checkout of the `v0.3.2` tag, without `ALLOW_UNTAGGED`.
- Run the [installed GUI checklist](https://github.com/AojdevStudio/materialize-3d/blob/v0.3.2/docs/verify-on-mac.md) on that exact DMG.
- Store the software acceptance record in the meta repo, not on the release. The record and the release body name the exact tagged source commit and the full DMG checksum. Keep those values out of tracked source.
- Publish only the DMG and the three update files.
- Download the published files and compare them with the build, as the release procedure's last step says.

## Installation

Download `Materialize-3D-0.3.2-macos-arm64.dmg` from the [published release](https://github.com/AojdevStudio/materialize-3d/releases/tag/v0.3.2). Follow the [Mac install guide](https://github.com/AojdevStudio/materialize-3d/blob/v0.3.2/docs/install-macos.md). Compare the downloaded DMG's full checksum with the DMG SHA-256 in the release body, and stop on a mismatch.

```bash
shasum -a 256 ~/Downloads/Materialize-3D-0.3.2-macos-arm64.dmg
```

On 0.3.1, **Update now** installs 0.3.2 for you.
