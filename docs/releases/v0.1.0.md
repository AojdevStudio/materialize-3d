# Materialize 3D 0.1.0

The first public release. Materialize 3D turns a conversation into a print file you can check and approve before it leaves the app. This release does one workflow end to end: three-color signs for the Bambu Lab P2S.

## What works

- Describe a sign to the in-app assistant (Anthropic or OpenAI, with your own API key).
- The app builds a face-down, three-color sign package and slices it with Bambu Studio 02.08.02.61 using P2S 0.4 mm presets.
- 27 automated geometry and slice checks, including first-layer coverage for each color.
- You approve the exact package by its SHA-256 hash. The assistant cannot approve, and any change makes a new revision that needs its own approval.
- Export a 3MF through the macOS Save dialog, then open and print it from Bambu Studio.
- An optional local MCP endpoint, off by default and loopback only, for other agents. It cannot approve either.

## Requirements

- A Mac with Apple Silicon. Tested on macOS 26.7. The app declares macOS 13 as its minimum; macOS 13 to 15 are untested. No Intel, Windows, or Linux build is offered.
- Bambu Studio 02.08.02.61 from Bambu Lab, installed separately. Materialize 3D does not include it.
- An Anthropic or OpenAI API key. The provider bills each request at its own rates; the app is free.
- To print: a Bambu Lab P2S with an AMS and three filaments.

## Install

Download `Materialize-3D-0.1.0-macos-arm64.dmg`, open it, drag Materialize 3D into Applications, and open it. The app is signed with a Developer ID and notarized by Apple. The full guide, including Bambu Studio setup, is `docs/install-macos.md`.

Check the download against the attached `.sha256` file:

```bash
shasum -a 256 ~/Downloads/Materialize-3D-0.1.0-macos-arm64.dmg
```

## How this release was checked

The DMG was built from the tagged commit by `scripts/release/build-macos.sh`, which signs with the hardened runtime, notarizes and staples the app and the DMG, and checks Gatekeeper acceptance, the architecture, the absence of the test harness, and the exact contents of the app bundle. The installed app then passed Gatekeeper as a notarized download, migrated existing data, kept the MCP endpoint off by default, stored and reread its own keychain credential, and built the acceptance sign with all 27 checks passing.

Physical printing is not part of these checks. A printed test sign is a separate acceptance step (`docs/acceptance/p2s-test-sign.md`), and no print result is recorded on anyone's behalf.

## Known limitations

- Signs only, on the P2S with a 0.4 mm nozzle.
- Materialize 3D does not send jobs to the printer. You print from Bambu Studio.
- Earlier tools in the app (model library, 3D preview, MakerWorld browser, OpenSCAD editor, print monitor, print history) are not part of the validated workflow.
